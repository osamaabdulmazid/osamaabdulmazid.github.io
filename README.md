# Osama Abdul Mazid — Premium Portfolio

A futuristic, dark-purple portfolio designed for GitHub Pages.

## Files

- `index.html` — page structure
- `styles.css` — all visual design and responsive layout
- `data.js` — **EDIT THIS FILE to update your information**
- `script.js` — renders the data and handles interactions
- `assets/profile.jpg` — profile photo extracted from the supplied CV

## How to edit

Open `data.js`. Almost all personal information is stored there:
- name / role / tagline
- email / phone / LinkedIn
- stats
- focus areas
- experience
- education
- skills
- certifications
- achievements
- languages
- reference

You do not need to change the HTML when updating normal portfolio information.

## GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload everything inside this folder.
3. Go to repository Settings → Pages.
4. Select the main branch as the deployment source.
5. Your site will become available at your GitHub Pages address.
