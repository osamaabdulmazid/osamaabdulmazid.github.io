## Google/entity setup after publishing
1. Verify the site in Google Search Console.
2. Submit `https://osamaabdulmazid.github.io/sitemap.xml`.
3. Use URL Inspection for the homepage and request indexing.
4. Validate the structured data with Google's Rich Results Test.
5. Keep the same exact name, profile photo, job identity, education history and social URLs across public profiles.
6. Add independent articles, interviews, organization pages, awards, event pages, or other third-party references when they genuinely exist. Do not manufacture coverage or fake citations.

Structured data helps Google understand the page, but Google does not guarantee a Knowledge Panel or rich result. Independent, authoritative web references are what strengthen entity recognition over time.
